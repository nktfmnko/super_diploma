# super_diploma

## ВКР по теме: Реализация системы обмена данными между мобильными устройствами без подключения к серверу

Целью данной выпускной квалификационной работы является реализация мобильного приложения на фреймворке Flutter для организации системы обмена данными между мобильными устройствами без подключения к серверу.

Приложение позволяет пользователям находить устройства поблизости, устанавливать прямое соединение и обмениваться сообщениями без использования промежуточного сервера.

Технологии:
- Flutter / Dart — разработка мобильного приложения
- Wi-Fi Direct — обнаружение устройств и организация прямого соединения между ними
- TCP Sockets — передача данных между подключёнными устройствами
- P2P-архитектура — обмен данными происходит непосредственно между устройствами
